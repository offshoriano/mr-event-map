# Agente de respostas do Matheus Rangel

Base de conhecimento e regras do agente que responde comentários do canal Carreira Offshore no YouTube.

Pasta interna. O `.htaccess` bloqueia o acesso pelo site. Não é conteúdo do mrgroup.com.br.

- `AGENTE-MATHEUS-v2.md`: o arquivo principal, com tudo junto e a ordem de prioridade. É o que a tarefa semanal lê.
- `regras-adicionais-agente.md`, `base-faq-matheus.md`, `base-historia-matheus.md`: as partes, separadas.
- `base-v1-original.md`: a base que o Matheus escreveu primeiro.
- `entrevista-matheus.md`: as perguntas usadas na entrevista.
- `respondidos.md`: registro do que a tarefa semanal já publicou.

Pra atualizar a base, edite as partes e gere de novo o `AGENTE-MATHEUS-v2.md`, ou edite direto o arquivo principal.
